# Test Pages

## Test Overview

- Display each test in a card containing its title, date, time limit, and status.
- Selecting a test card opens the individual test page.
- Display the signed-in user's name and account role.
- Use placeholder test data until test entities are implemented in the database.

## Individual Test Page

- Display the test title, date, time limit, and a visible countdown placeholder.
- Automatically display the signed-in student's name and e-mail address.
- Display each question with its available points and an answer field.
- Include a submit button.
- Answers and submissions are not persisted during this phase.

## Test Creation

- Only teacher accounts can access this page.
- Include fields for the test title, date, time limit, status, and instructions.
- Question creation and saving are not implemented during this phase.
