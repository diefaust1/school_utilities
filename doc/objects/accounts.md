Accounts
- students and teachers

Student account
- first name, last name (editable from Account Info)
- Date of creation
- E-Mail (will not be verified)
- Password


Teacher accounts
- first name, last name (editable from Account Info)
- Date of creation
- E-Mail (will not be verified)
- Password
- Can be selected during registration
- Are able to access the Test-Creation page

Account Info page
- Signed-in users can change their first and last name.
- The Save Changes button validates and stores the names in the database.
- E-mail address and account type are currently read-only.
