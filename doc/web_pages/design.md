# Shared Page Design

## Authenticated Pages

All pages shown after login use the same responsive layout:

- A navigation sidebar appears on the left on desktop screens.
- The sidebar becomes a top navigation area on smaller screens.
- The main content appears to the right of the sidebar.
- The active navigation item is visually highlighted.
- A sign-out button is available from every authenticated page.

The navigation contains:

- Test Overview
- Test Creation, visible only to teachers
- Account Info

## Public Pages

The login and registration pages do not use the navigation sidebar. They display a centered card with the relevant form.

## Visual Style

- Keep the interface simple and readable.
- Use consistent spacing, colors, form controls, cards, and focus states.
- Support desktop and mobile screen sizes.
