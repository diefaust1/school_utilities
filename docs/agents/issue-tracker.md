# Issue Tracker: GitHub Issues

Issues for this repo live in GitHub Issues:

```text
https://github.com/diefaust1/school_utilities/issues
```

## Conventions

- Use GitHub Issues for bugs, feature requests, implementation tasks, and follow-up work.
- Use the triage labels defined in `docs/agents/triage-labels.md`.
- External pull requests are not treated as a triage request surface.

## When A Skill Says "Publish To The Issue Tracker"

Create a GitHub Issue in this repository, using the `gh` CLI when available.

## When A Skill Says "Fetch The Relevant Ticket"

Read the referenced GitHub Issue from this repository.
